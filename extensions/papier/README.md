# Papier

Thème clair ton papier, accent terre cuite. Fond crème et encre brune : repose les yeux en pleine journée.

Thème pour Tools Launcher : une fois installé, choisissez-le dans **Launcher > Thème**.

Les contrastes respectent les seuils WCAG (texte 4,5:1 ; éléments d'interface 3:1), vérifiés par les tests du projet. Les couleurs absentes (avertissement, fond d'avertissement) viennent du thème sombre.
